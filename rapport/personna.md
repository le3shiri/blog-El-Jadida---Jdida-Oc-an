# 👥 Personas – Projet "El Jadida Océan & Ilyas El Maliki"

## 👤 Persona 1 : Salma, étudiante engagée
| Élément | Description |
|----------|--------------|
| **Nom** | Salma, étudiante engagée |
| **Âge / situation** | 21 ans, étudiante en sciences de l’environnement à l’Université Chouaïb Doukkali |
| **Objectif principal** | Participer à des actions écologiques locales et suivre les initiatives environnementales de la région |
| **Besoins clés** | Contenus simples, inspirants et diffusés sur les réseaux sociaux (Instagram, TikTok) |
| **Frustrations** | Manque d’informations claires sur les événements écologiques, faible visibilité des associations locales |
| **Environnement** | Utilise son smartphone pour s’informer, suit des influenceurs marocains comme Ilyas El Maliki, connectée en 4G |

---

## 👤 Persona 2 : Youssef, jeune entrepreneur local
| Élément | Description |
|----------|--------------|
| **Nom** | Youssef, entrepreneur local |
| **Âge / situation** | 28 ans, gérant d’un café en bord de mer à El Jadida |
| **Objectif principal** | Attirer plus de clients tout en contribuant à la protection du littoral |
| **Besoins clés** | Collaborations locales, visibilité via les campagnes éco-digitales |
| **Frustrations** | Manque de soutien des autorités, faible engagement des habitants |
| **Environnement** | Travaille sur ordinateur portable, suit les tendances locales sur Facebook et TikTok |

---

## 👤 Persona 3 : Mme Khadija, représentante associative
| Élément | Description |
|----------|--------------|
| **Nom** | Mme Khadija, activiste écologique |
| **Âge / situation** | 40 ans, présidente d’une association locale pour la protection du littoral |
| **Objectif principal** | Sensibiliser les jeunes et créer des partenariats avec des influenceurs comme Ilyas El Maliki |
| **Besoins clés** | Soutien médiatique, outils de communication modernes, bénévoles motivés |
| **Frustrations** | Difficulté à mobiliser les jeunes, manque de financement et de visibilité |
| **Environnement** | Utilise Facebook et WhatsApp pour communiquer avec la communauté, peu familière avec TikTok |

---

📌 **Synthèse**
Ces trois personas représentent les publics cibles du projet **“Jdida Océan”** :
- **Salma** : la jeunesse étudiante connectée et motivée.  
- **Youssef** : les acteurs économiques locaux cherchant un équilibre entre business et écologie.  
- **Mme Khadija** : les associations de terrain nécessitant un appui en communication.

L’implication d’un influenceur comme **Ilyas El Maliki** pourrait relier ces trois profils autour d’un même objectif :  
👉 **protéger le littoral d’El Jadida tout en mobilisant la société à travers les réseaux sociaux.**
