# 🌊 Projet : Jdida Océan – Promotion des initiatives écologiques avec Ilyas El Maliki

## 🧩 Tableau des fonctionnalités priorisées (Méthode MoSCoW)

| Priorité | Fonctionnalité | Description |
|-----------|----------------|--------------|
| **Must Have** | Page d’accueil interactive | Présente les initiatives écologiques locales et la participation d’Ilyas El Maliki |
| **Must Have** | Carte du littoral | Affiche les zones concernées par les actions écologiques (plages, associations, événements) |
| **Should Have** | Système d’inscription aux événements | Permet aux utilisateurs de participer aux campagnes de nettoyage ou ateliers |
| **Could Have** | Espace communauté | Espace de discussion entre bénévoles, étudiants et associations locales |
| **Won’t Have (pour l’instant)** | Application mobile complète | Version web priorisée avant le développement d’une app mobile |

---

## 📘 Liste des cas d’utilisation (Use Cases)

| UC ID | Titre | Acteurs principaux | Brève description |
|--------|--------|---------------------|------------------|
| **UC1** | Consulter les initiatives écologiques | Utilisateur | L’utilisateur peut parcourir les projets écologiques du littoral d’El Jadida |
| **UC2** | S’inscrire à une action environnementale | Utilisateur | L’utilisateur s’enregistre pour participer à une campagne de nettoyage |
| **UC3** | Publier une initiative | Association / Admin | L’association ajoute un nouvel événement ou une activité écologique |
| **UC4** | Promouvoir via influenceur | Ilyas El Maliki / Admin | L’admin collabore avec Ilyas El Maliki pour publier une campagne de sensibilisation |
| **UC5** | Partager une action sur les réseaux | Utilisateur | L’utilisateur partage sur les réseaux sociaux les actions écologiques auxquelles il participe |
